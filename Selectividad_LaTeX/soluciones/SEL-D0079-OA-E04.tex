\textbf{a)} La población es normal y la desviación típica $\sigma=0{,}05$ segundos es conocida. El intervalo normal para la media usa el error estándar $\sigma/\sqrt n$. Al $99\%$, cada cola tiene probabilidad $0{,}005$ y $z_{0{,}995}\approx2{,}5758$:
\[
 0{,}85\pm2{,}5758\frac{0{,}05}{\sqrt{50}}
 \approx\boxed{[0{,}83179;\ 0{,}86821]}\ \text{segundos}.
\]
\textbf{b)} Al $95\%$ usamos $z_{0{,}975}\approx1{,}96$. Exigimos que el margen sea como máximo $0{,}01$:
\[
 \frac{1{,}96\cdot0{,}05}{\sqrt n}\le0{,}01
 \quad\Longrightarrow\quad n\ge9{,}8^2=96{,}04.
\]
Redondeamos hacia arriba para garantizar el error pedido. La muestra mínima contiene $\boxed{97}$ conductores.
