\textbf{a)} Con población normal y $\sigma=25$ conocida,
el intervalo es $\bar x\pm z_{1-\alpha/2}\sigma/\sqrt n$.
Para confianza del $96\%$ se usa $z_{0.98}\approx2.053749$.
Así, $230\pm2.053749(25/10)\approx\boxed{[224.866,\ 235.134]\text{ g}}$.

\textbf{b)} El margen es la semiamplitud, aproximadamente
$\boxed{5.134\text{ g}}$.

\textbf{c)} Interpretamos 2 g como el error máximo permitido.
La condición $z_{0.98}\,25/\sqrt n\le2$ exige
$n\ge(25z_{0.98}/2)^2\approx659.0445$. El menor entero válido
es $\boxed{660}$. Con el cuantil tabulado $2.05$ se obtendría
$657$, pero al usar el cuantil con más precisión, esa muestra
supera el margen de 2 g.
