\textbf{a)} La proporción observada es $\hat p=80/120=2/3$.
Hay 80 casos favorables y 40 restantes. Para la aproximación
normal bilateral al $92\%$ usamos $z_{0.96}\approx1.750686$:
\[
\hat p\pm z_{0.96}\sqrt{\frac{\hat p(1-\hat p)}{120}}
\approx\boxed{[0.5913,\ 0.7420]}.
\]
\textbf{b)} Con la misma muestra, el error aumenta porque
$z_{0.995}>z_{0.96}$. El intervalo se ensancha.

\textbf{c)} Usando $2/3$ como estimación previa, imponemos
$z_{0.995}\sqrt{(2/3)(1/3)/n}\le0.04$. Al cuadrar,
$n\ge z_{0.995}^2(2/9)/0.04^2\approx921.5134$.
El mínimo es $\boxed{922}$ establecimientos. Si se exige
cubrir el peor caso para una proporción desconocida, se sustituye
$2/9$ por $1/4$ y se obtienen 1037 establecimientos.
