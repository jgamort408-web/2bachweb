Se considera la matriz $A=\begin{pmatrix}2&1&0\\1&0&2\\0&2&a\end{pmatrix}$.
\begin{enumerate}[label=\alph*)]
  \item \textbf{(0.7 puntos)} Determine para qué valores del parámetro $a$,
  la matriz $A$ tiene inversa.
  \item \textbf{(1 punto)} Para $a=1$, calcule la inversa de $A$.
  \item \textbf{(0.8 puntos)} Para $a=1$, resuelva la ecuación matricial
  $A\cdot X=B^t$, siendo $B=\begin{pmatrix}0&1&-1\end{pmatrix}$.
\end{enumerate}
