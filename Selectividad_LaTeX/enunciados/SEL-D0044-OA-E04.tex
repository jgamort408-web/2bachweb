Para estimar la proporción de balances contables incorrectos de un banco, se seleccionan aleatoriamente 200 balances, y se encuentra que 19 de ellos son incorrectos.
\begin{enumerate}[label=\alph*)]
\item \textbf{(1.5 puntos)} Obtenga un intervalo de confianza, al 95\%, para la proporción de balances incorrectos.
\item \textbf{(1 punto)} \textquestiondown{}Cuántos balances se deberán seleccionar para que, con un nivel de confianza del 99\%, el error de la estimación no sea superior a 0.02?
\end{enumerate}
