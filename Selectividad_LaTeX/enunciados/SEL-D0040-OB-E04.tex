De una población Normal de media desconocida $\mu$ y desviación típica 2 se extrae la siguiente muestra aleatoria simple de tamaño 10:
\[
3.8\quad6.3\quad4.3\quad6\quad6.2\quad5.8\quad1.5\quad3.3\quad3.4\quad2.9
\]
\begin{enumerate}[label=\alph*)]
\item \textbf{(1.5 puntos)} Estime, mediante un intervalo de confianza, la media poblacional para un nivel de confianza del 92\%. Obtenga su error de estimación.
\item \textbf{(1 punto)} \textquestiondown{}Qué tamaño muestral mínimo sería necesario para reducir ese error a la mitad, con el mismo nivel de confianza?
\end{enumerate}
