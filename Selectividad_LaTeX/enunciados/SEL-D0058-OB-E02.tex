Sea la función
\[
f(x)=\begin{cases}x^2-3x+4&\text{si }x\leq2\\[0.8em]4-\dfrac{a}{x}&\text{si }x>2\end{cases}
\]
\begin{enumerate}[label=\alph*)]
\item \textbf{(1.5 puntos)} Halle el valor de $a$ para que dicha función sea continua y estudie la derivabilidad de $f$ para ese valor de $a$.
\item \textbf{(1 punto)} Para $a=1$, \textquestiondown{}existe alguna asíntota vertical de esa función? \textquestiondown{}Y horizontal? Razone las respuestas y calcule, en caso afirmativo, dichas asíntotas.
\end{enumerate}
