            <h2>¿Qué es un Intervalo de Confianza?</h2>
            <div class="theory-grid" style="margin-top: 1.5rem;">
                <div>
                    <p>En estadística, casi nunca podemos conocer la verdadera media de toda una población ($\mu$) porque sería infinito o muy caro medir a todo el mundo.</p>
                    <p style="margin-top: 1rem;">Lo que hacemos es tomar una <strong>muestra</strong>, calcular su media ($\bar{x}$) y construir un "margen" alrededor de ella. A ese margen lo llamamos Intervalo de Confianza.</p>
                </div>
                <div class="analogy-box">
                    <strong>🎣 La analogía de la red de pesca:</strong><br><br>
                    Imagina que intentas pescar un pez invisible (la media poblacional). Lanzar un arpón es como intentar adivinar el número exacto: casi seguro fallarás.<br><br>
                    El intervalo de confianza es como <strong>lanzar una red</strong>. Cuanto más grande sea la red (mayor nivel de confianza), más seguros estamos de atrapar al pez, pero menos precisos somos sobre en qué punto exacto de la red está.
                </div>
            </div>
        </section>

        <section class="card">
            <h2>La Anatomía de la Fórmula</h2>
            <p style="margin-top: 1rem;">Un intervalo de confianza siempre tiene la estructura: <strong>Centro $\pm$ Error</strong>.</p>
            
            <div style="font-size: 1.5rem; text-align: center; margin: 1.5rem 0; padding: 1.5rem; background: var(--blueprint-bg); border-radius: 8px;">
                $$IC = \left[ \bar{x} - z_{\alpha/2} \cdot \frac{\sigma}{\sqrt{n}} , \bar{x} + z_{\alpha/2} \cdot \frac{\sigma}{\sqrt{n}} \right]$$
            </div>

            <div class="formula-breakdown">
                <div class="math-pill">
                    <span class="math-pill-title">El Centro</span>
                    <span style="font-size: 1.2rem; font-family: 'JetBrains Mono'; margin-top: 0.5rem;">$\bar{x}$</span>
                    <span style="font-size: 0.8rem; color: var(--text-light); text-align: center; margin-top: 0.25rem;">La media de nuestra muestra. Es nuestro punto de anclaje.</span>
                </div>
                <div class="math-pill">
                    <span class="math-pill-title">Confianza</span>
                    <span style="font-size: 1.2rem; font-family: 'JetBrains Mono'; margin-top: 0.5rem;">$z_{\alpha/2}$</span>
                    <span style="font-size: 0.8rem; color: var(--text-light); text-align: center; margin-top: 0.25rem;">Valor crítico de la tabla normal. Multiplica el error.</span>
                </div>
                <div class="math-pill">
                    <span class="math-pill-title">Incertidumbre</span>
                    <span style="font-size: 1.2rem; font-family: 'JetBrains Mono'; margin-top: 0.5rem;">$\sigma / \sqrt{n}$</span>
                    <span style="font-size: 0.8rem; color: var(--text-light); text-align: center; margin-top: 0.25rem;">El error estándar. Disminuye si encuestamos a más gente ($n$).</span>
                </div>
            </div>

    <script>
        const elXbar = document.getElementById('xbar');
        const elSigma = document.getElementById('sigma');
        const elN = document.getElementById('n');
        const elConfianza = document.getElementById('confianza');

        const valXbar = document.getElementById('val-xbar');
        const valSigma = document.getElementById('val-sigma');
        const valN = document.getElementById('val-n');
        const eqE = document.getElementById('eq-e');

        const svgInterval = document.getElementById('svg-interval');
        const svgXbar = document.getElementById('svg-xbar');
        const svgXbarText = document.getElementById('svg-xbar-text');
        const svgLowerText = document.getElementById('svg-lower-text');
        const svgUpperText = document.getElementById('svg-upper-text');
        const svgArrowLeft = document.getElementById('svg-arrow-left');
        const svgArrowRight = document.getElementById('svg-arrow-right');
        const svgErrorGroup = document.getElementById('svg-error-group');

        function updateSimulation() {
            const xbar = parseFloat(elXbar.value);
            const sigma = parseFloat(elSigma.value);
            const n = parseInt(elN.value);
            const z = parseFloat(elConfianza.value);

            const E = z * (sigma / Math.sqrt(n));
            const lower = xbar - E;
            const upper = xbar + E;
            const width = Math.max(upper - lower, 0.5);

            valXbar.textContent = xbar;
            valSigma.textContent = sigma;
            valN.textContent = n;
            eqE.textContent = E.toFixed(2);

            // Actualizar la caja del intervalo y la media
            svgInterval.setAttribute('x', lower);
            svgInterval.setAttribute('width', width);
            svgXbar.setAttribute('cx', xbar);
            svgXbarText.setAttribute('x', xbar);
            
            svgLowerText.textContent = lower.toFixed(1);
            svgUpperText.textContent = upper.toFixed(1);

            // MEJORA 2: Lógica dinámica de posicionamiento de texto para evitar solapamientos
            if (width < 14) {
                // Si el intervalo es muy pequeño, escalonamos los textos verticalmente y los centramos a su marca
                svgLowerText.setAttribute('y', 106); // Baja un poco más
                svgUpperText.setAttribute('y', 94);  // Sube un poco
                svgLowerText.setAttribute('text-anchor', 'middle');
                svgUpperText.setAttribute('text-anchor', 'middle');
                svgLowerText.setAttribute('x', lower);
                svgUpperText.setAttribute('x', upper);
                
                // Ocultar las flechas superiores porque se ven mal al estar todo tan apretado
                svgErrorGroup.style.opacity = "0";
            } else {
                // Si hay espacio suficiente, los ponemos alineados horizontalmente pero anclados hacia fuera
                svgLowerText.setAttribute('y', 100);
                svgUpperText.setAttribute('y', 100);
                svgLowerText.setAttribute('text-anchor', 'end'); // Escribe hacia la izquierda
                svgUpperText.setAttribute('text-anchor', 'start'); // Escribe hacia la derecha
                svgLowerText.setAttribute('x', lower - 1); // Separamos un pixel del borde
                svgUpperText.setAttribute('x', upper + 1);
                
                // Mostrar las flechas
                svgErrorGroup.style.opacity = "1";
            }

            // Actualizar flechas de error siempre, aunque estén invisibles (previene saltos al reaparecer)
            svgArrowLeft.setAttribute('x1', xbar);
            svgArrowLeft.setAttribute('x2', lower + 0.5);
            svgArrowRight.setAttribute('x1', xbar);
            svgArrowRight.setAttribute('x2', upper - 0.5);
        }

        elXbar.addEventListener('input', updateSimulation);
        elSigma.addEventListener('input', updateSimulation);
        elN.addEventListener('input', updateSimulation);
        elConfianza.addEventListener('change', updateSimulation);

        updateSimulation();
    </script>
