        <section class="card">
            <span class="section-tag">01. MARCO TEÓRICO</span>
            <h2>¿Qué es la distribución muestral?</h2>
            <p style="margin-top: 1rem;">En estadística, la <strong>distribución muestral</strong> es lo que resulta al considerar todas las muestras posibles que se pueden tomar de una población.</p>
            <p style="margin-top: 1rem;">Su objetivo es generalizar correctamente los resultados de la muestra a la población y, así, inferir o predecir el comportamiento de la población a partir del conocimiento de esta muestra. Permite calcular la probabilidad (dada una sola muestra) de acercarse al parámetro de la población que se pretende estudiar.</p>
            
            <div style="text-align: center; margin: 2rem 0;">
                            </div>

            <h3 style="margin-top: 2rem;">El Teorema Central del Límite (TCL)</h3>
            <p style="margin-top: 1rem;">Sea una distribución normal con una media $\mu$ y una desviación típica $\sigma$, es decir, $N(\mu, \sigma)$. Al extraer muestras de tamaño $n$ y calcular sus medias, obtenemos una nueva distribución.</p>
            
            <div style="background: #f8fafc; border-left: 4px solid var(--primary); padding: 1.5rem; margin-top: 1.5rem;">
                <p>Según el <strong>teorema central del límite</strong>, la distribución de las medias de las muestras de tamaño $n$ cumple que:</p>
                <ul style="margin-left: 1.5rem; margin-top: 1rem; line-height: 1.8;">
                    <li>Tiene la misma media, $\mu$, que la población total.</li>
                    <li>Su desviación típica es $\frac{\sigma}{\sqrt{n}}$; por consiguiente, disminuye al aumentar $n$.</li>
                    <li>Cuando $n \ge 30$, la distribución se aproxima a la distribución normal.</li>
                </ul>
            </div>
            
            <div class="formula-box">
                Distribución de las Medias Muestrales: $\bar{X} \sim N\left(\mu, \frac{\sigma}{\sqrt{n}}\right)$
            </div>
        </section>

        <section class="example-box">
            <span class="section-tag" style="color: #92400e;">02. CASO PRÁCTICO RESUELTO</span>
            <h3>Control de Calidad: Peso del Café</h3>
            <p>Una máquina empaqueta bolsas de café. El peso de las bolsas sigue una distribución normal con una media de 500 gramos y una desviación típica de 15 gramos; es decir, $N(500, 15)$.</p>
            
            <div style="margin-top: 1.5rem; padding-bottom: 1rem; border-bottom: 1px solid #fcd34d;">
                <strong>a) Probabilidad Individual:</strong> Si se elige una bolsa al azar, ¿cuál es la probabilidad de que pese menos de 495 gramos?
                <p style="margin-top: 0.5rem; color: #78350f;">Al igual que en el caso del tiempo de espera del banco estudiado en la unidad anterior, se trabaja con un solo individuo. Tipificamos usando $\sigma = 15$:</p>
                $$Z = \frac{x - \mu}{\sigma} = \frac{495 - 500}{15} = -0.33$$
                $$P(X < 495) = P(Z < -0.33) = 1 - P(Z \le 0.33) = 1 - 0.6293 = \mathbf{0.3707 \ (37.07\%)}$$
            </div>

            <div style="margin-top: 1.5rem;">
                <strong>b) Probabilidad Muestral:</strong> Si se escoge una muestra al azar de 25 bolsas, ¿cuál es la probabilidad de que el peso <em>medio</em> de esa muestra sea inferior a 495 gramos?
                <p style="margin-top: 0.5rem; color: #78350f;">En este caso, tenemos una distribución de medias. Por tanto, debemos usar el teorema central del límite para encontrar los nuevos parámetros. La nueva desviación es $\frac{\sigma}{\sqrt{n}}$:</p>
                $$\bar{X} \sim N\left(500, \frac{15}{\sqrt{25}}\right) = N(500, 3)$$
                <p style="margin-top: 0.5rem; color: #78350f;">Ahora, ya podemos seguir el mismo proceso que antes:</p>
                $$Z = \frac{\bar{x} - \mu}{\frac{\sigma}{\sqrt{n}}} = \frac{495 - 500}{3} = -1.67$$
                $$P(\bar{X} < 495) = P(Z < -1.67) = 1 - P(Z \le 1.67) = 1 - 0.9525 = \mathbf{0.0475 \ (4.75\%)}$$
            </div>
            <p style="margin-top: 1rem; font-size: 0.9rem; color: #78350f; font-style: italic;">*Nota: Fíjate cómo la variabilidad disminuye radicalmente al tomar una muestra en lugar de un individuo aislado. Es mucho más difícil que 25 bolsas juntas tengan una media baja, a que una sola bolsa salga baja.</p>
        </section>

        function checkAnswer(step, isCorrect) {
            const fb = document.getElementById('fb' + step);
            const btn = document.getElementById('next' + step);
            
            fb.style.display = 'block';
            fb.className = 'adv-feedback ' + (isCorrect ? 'success' : 'error');
            
            if (isCorrect) {
                fb.innerHTML = "<strong>¡Decisión Matemática Correcta!</strong> Excelente análisis.";
                btn.style.display = 'inline-block';
            } else {
                if (step === 1) {
                    fb.innerHTML = "<strong>Error:</strong> Recuerda que la desviación típica de la distribución de las medias muestrales es $\\frac{\\sigma}{\\sqrt{n}}$. Revisa tus cálculos.";
                } else if (step === 2) {
                    fb.innerHTML = "<strong>Error:</strong> Para tipificar la media muestral, debes usar la desviación típica que calculaste en el paso 1 ($10$), no la desviación de la población general ($80$). Además, fíjate en el orden del numerador: $\\bar{x} - \\mu$.";
                } else if (step === 3) {
                    fb.innerHTML = "<strong>Error:</strong> Estás buscando el área en la cola izquierda ($< -2.00$). Como la tabla da áreas hacia la izquierda de valores positivos, debes hacer $1 - 0.9772$.";
                }
                btn.style.display = 'none';
            }
            
            if (window.MathJax) MathJax.typesetPromise([fb]);
        }
