        <section class="card">
            <span class="section-tag">01. MARCO TEÓRICO</span>
            <h2>Concepto de Proporción Muestral</h2>
            <p style="margin-top: 1rem;">En muchas ocasiones, se precisa estimar una proporción o porcentaje de observaciones que cumplan una determinada característica. Esto ocurre cuando la variable aleatoria que se estudia puede tomar solo dos valores diferentes: <strong>sí (éxito) y no (fracaso)</strong>.</p>
            
            <p style="margin-top: 1rem;">Por ejemplo, el porcentaje de personas que votan a un partido, a las que les ha funcionado un tratamiento médico, o dispuestas a comprar un coche. En todos estos casos estamos ante una <strong>distribución binomial</strong>, $B(n,p)$.</p>

            <div style="background: #f8fafc; border-left: 4px solid var(--secondary); padding: 1.5rem; margin-top: 1.5rem;">
                <p>Dada una muestra aleatoria de tamaño $n$ en la que se producen $x$ éxitos, se deduce que la <strong>proporción de éxitos de la muestra</strong> (designada como $\hat{p}$) viene dada por:</p>
                <div class="formula-box" style="background: white; border-color: #e2e8f0; margin: 1rem 0;">
                    $$\hat{p} = \frac{x}{n}$$
                </div>
            </div>

            <h3 style="margin-top: 2rem;">Aplicación del Teorema Central del Límite</h3>
            <p style="margin-top: 1rem;">Como se ha visto anteriormente, cuando la muestra es suficientemente grande ($n \ge 30$) y cumple ciertas condiciones ($n \cdot p > 5$ y $n \cdot q > 5$), se puede aproximar a una distribución normal.</p>
            
            <p style="margin-top: 1rem;">Mediante el Teorema Central del Límite, se puede inferir que la distribución muestral de proporciones sigue una distribución normal con los siguientes parámetros:</p>
            
            <ul class="highlight-list">
                <li>Tiene la misma media $\mu$ que la población: $\mu = p$.</li>
                <li>Presenta una desviación típica de $\sigma = \sqrt{\frac{p \cdot q}{n}}$.</li>
            </ul>
            
            <div class="formula-box">
                Modelo de la Proporción: $\hat{P} \to N\left(p, \sqrt{\frac{p \cdot q}{n}}\right)$
            </div>
        </section>

        <section class="example-box">
            <span class="section-tag" style="color: #92400e;">02. CASO PRÁCTICO RESUELTO</span>
            <h3>Hábitos de Consumo: Pequeño Comercio</h3>
            <p>Según datos de la asociación de empresarios, el $20\%$ de las personas hace sus compras de alimentación en pequeños comercios de barrio ($p=0.20$), mientras que el $80\%$ restante compra en grandes superficies o internet ($q=0.80$). Se escoge una muestra de $50$ personas ($n=50$).</p>
            
            <p style="margin-top: 1rem; color: #78350f;"><strong>Paso 1: Definir la distribución</strong></p>
            <p style="color: #78350f;">Calculamos la desviación típica usando $\sigma = \sqrt{\frac{p \cdot q}{n}}$:</p>
            $$\sigma = \sqrt{\frac{0.20 \cdot 0.80}{50}} = \sqrt{\frac{0.16}{50}} = \sqrt{0.0032} \approx 0.057$$
            <p style="color: #78350f;">Por tanto, la distribución es $\hat{P} \sim N(0.20, 0.057)$.</p>

            <div style="margin-top: 1.5rem; padding-top: 1rem; border-top: 1px solid #fcd34d;">
                <strong>Pregunta:</strong> Determina la probabilidad de que la proporción de la muestra sea superior al 25% ($\hat{P} > 0.25$).
                <p style="margin-top: 0.5rem; color: #78350f;">Primero, tipificamos el valor:</p>
                $$Z = \frac{0.25 - 0.20}{0.057} = 0.88$$
                <p style="margin-top: 0.5rem; color: #78350f;">Buscamos en la tabla de la Normal estándar:</p>
                $$P(\hat{P} > 0.25) = P(Z > 0.88) = 1 - P(Z \le 0.88) = 1 - 0.8106 = \mathbf{0.1894 \ (18.94\%)}$$
            </div>
        </section>

        function checkAnswer(step, isCorrect) {
            const fb = document.getElementById('fb' + step);
            const btn = document.getElementById('next' + step);
            
            fb.style.display = 'block';
            fb.className = 'adv-feedback ' + (isCorrect ? 'success' : 'error');
            
            if (isCorrect) {
                fb.innerHTML = "<strong>¡Decisión Matemática Correcta!</strong> Has aplicado bien la teoría.";
                btn.style.display = 'inline-block';
            } else {
                if (step === 1) {
                    fb.innerHTML = "<strong>Error:</strong> Recuerda que la desviación típica lleva una raíz cuadrada: $\\sigma = \\sqrt{\\frac{p \\cdot q}{n}}$. Has olvidado aplicar la raíz o has usado números enteros en vez de decimales para $p$ y $q$.";
                } else if (step === 2) {
                    fb.innerHTML = "<strong>Error:</strong> Para tipificar debes restar: $\\frac{\\text{Valor objetivo} - \\text{Media poblacional}}{\\sigma}$. Es decir, $\\frac{0.20 - 0.15}{0.0357}$.";
                } else if (step === 3) {
                    fb.innerHTML = "<strong>Error:</strong> La tabla te da la probabilidad de estar por DEBAJO de ese valor ($P(Z \\le 1.40) = 91.92\\%$). Como te piden la probabilidad de que la proporción sea MAYOR ($>$), debes calcular el área restante: $1 - 0.9192$.";
                }
                btn.style.display = 'none';
            }
            
            if (window.MathJax) MathJax.typesetPromise([fb]);
        }
