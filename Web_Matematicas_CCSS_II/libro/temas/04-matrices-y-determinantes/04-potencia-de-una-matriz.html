4.4. Potencia de una matriz

Repetir una misma transformación conduce a multiplicar una matriz por sí misma. Las primeras potencias permiten descubrir patrones; justificarlos evita tener que hacer todos los productos.

Objetivos · Definición · Propiedades · Ejemplos · Explorador · Práctica · Tarjetas

1. Qué vas a aprender

  • Definir potencias enteras no negativas de matrices cuadradas.
  • Calcular A² y A³ mediante productos matriciales.
  • Reconocer y justificar patrones sencillos.
  • Interpretar una potencia como una transformación repetida.

Requisito: 4.3. Producto fila por columna y sus propiedades.

2. Una misma matriz como factor

Sea A una matriz cuadrada de orden r. Para exponentes enteros no negativos:

\[A^0=I_r,\qquad A^1=A,\qquad A^n=\underbrace{A\cdot A\cdots A}_{n\text{ factores}}\quad(n\ge1).\]

Para calcular AA, el número de columnas de A debe coincidir con sus filas: por eso exigimos una base cuadrada. Todas sus potencias conservan el orden r×r.

A² no significa elevar cada entrada al cuadrado ni calcular 2A. Se usa el producto fila por columna. El exponente cero se define como la identidad del orden correspondiente, también para una base nula o no invertible. Es una definición matricial; no se está calculando cada entrada como \(0^0\).

Esta lección trata exponentes 0,1,2,… Las potencias negativas requieren inversa, que se estudiará más adelante; no están definidas para toda matriz cuadrada.

3. Leyes y precauciones

Para una misma matriz cuadrada A y enteros m,n≥0:

\[A^mA^n=A^{m+n},\qquad(A^m)^n=A^{mn},\qquad A^{n+1}=A^nA.\]

La asociatividad permite reagrupar los factores A. La identidad hace que las reglas sigan funcionando cuando algún exponente es cero. Las potencias de una misma base conmutan entre sí: \(A^mA^n=A^nA^m\).

Con bases distintas no podemos reordenar factores libremente:

\[(AB)^2=ABAB,\qquad (A+B)^2=A^2+AB+BA+B^2.\]

En general \((AB)^2\ne A^2B^2\). Si AB=BA, sí se puede reagrupar para obtener A²B² y reunir AB+BA como 2AB.

Contraejemplo: para \(P=\begin{pmatrix}1&1\\0&1\end{pmatrix}\) y \(Q=\begin{pmatrix}1&0\\1&1\end{pmatrix}\),

\[(PQ)^2=\begin{pmatrix}5&3\\3&2\end{pmatrix},\qquad P^2Q^2=\begin{pmatrix}5&2\\2&1\end{pmatrix}.\]

Calcular dos o tres potencias sugiere un patrón, pero no demuestra que continúe para todos los exponentes. Para justificarlo, comprueba el primer caso y explica por qué multiplicar otra vez por A mantiene la fórmula.

4. Ejemplos resueltos

Ejemplo 1. Calcular A² y A³

\[A=\begin{pmatrix}1&2\\3&0\end{pmatrix}.\]

\[A^2=AA=\begin{pmatrix}1\cdot1+2\cdot3&1\cdot2+2\cdot0\\3\cdot1+0\cdot3&3\cdot2+0\cdot0\end{pmatrix}=\begin{pmatrix}7&2\\3&6\end{pmatrix}.\]

\[A^3=A^2A=\begin{pmatrix}7\cdot1+2\cdot3&7\cdot2+2\cdot0\\3\cdot1+6\cdot3&3\cdot2+6\cdot0\end{pmatrix}=\begin{pmatrix}13&14\\21&6\end{pmatrix}.\]

Reutilizamos A². En cambio, \(2A=\begin{pmatrix}2&4\\6&0\end{pmatrix}\): es otra operación.

Ejemplo 2. Una diagonal

\[D=\begin{pmatrix}2&0\\0&-1\end{pmatrix},\qquad D^n=\begin{pmatrix}2^n&0\\0&(-1)^n\end{pmatrix}\quad(n\ge0).\]

Al multiplicar diagonales, solo contribuyen los productos de entradas de su diagonal. Así \(D^2=\begin{pmatrix}4&0\\0&1\end{pmatrix}\) y \(D^3=\begin{pmatrix}8&0\\0&-1\end{pmatrix}\). El primer elemento crece y el segundo alterna entre 1 y −1. Para una diagonal que contenga ceros, se usa esta regla con n≥1 y se define aparte \(D^0=I\).

Ejemplo 3. Un patrón que alterna

\[S=\begin{pmatrix}0&1\\1&0\end{pmatrix},\qquad S^2=I.\]

Entonces \(S^{2k}=(S^2)^k=I\) y \(S^{2k+1}=S^{2k}S=S\), para k≥0. Por eso S²⁰=I y S²⁵=S. Aplicar S a un vector intercambia sus componentes; hacerlo dos veces las devuelve a su posición inicial.

Ejemplo 4. Anularse o repetirse

Para \(N=\begin{pmatrix}0&1\\0&0\end{pmatrix}\), N²=O. Cada potencia desde la segunda es nula: \(N^n=N^2N^{n-2}=O\) para n≥2. Sin embargo N¹=N y N⁰=I.

Para \(E=\begin{pmatrix}1&0\\0&0\end{pmatrix}\), E²=E. Si Eⁿ=E, al multiplicar por E se obtiene Eⁿ⁺¹=E²=E. Así Eⁿ=E para n≥1, pero E⁰=I. Este segundo patrón no es una alternancia.

Ejemplo 5. Acumulación por pasos

Consideremos un modelo ficticio en el que hay inicialmente 10 unidades y se añaden siempre 3 por paso. Guardamos cantidad e incremento en un vector columna:

\[T=\begin{pmatrix}1&1\\0&1\end{pmatrix},\qquad v_0=\begin{pmatrix}10\\3\end{pmatrix},\qquad v_{k+1}=Tv_k.\]

La primera fila suma cantidad e incremento; la segunda conserva el incremento. Calculamos \(v_1=\begin{pmatrix}13\\3\end{pmatrix}\) y \(v_2=\begin{pmatrix}16\\3\end{pmatrix}\).

\[T^n=\begin{pmatrix}1&n\\0&1\end{pmatrix},\qquad v_n=T^nv_0=\begin{pmatrix}10+3n\\3\end{pmatrix}.\]

Justificación: para n=0 la fórmula da I. Si vale para n, entonces

\[\begin{pmatrix}1&n\\0&1\end{pmatrix}\begin{pmatrix}1&1\\0&1\end{pmatrix}=\begin{pmatrix}1&n+1\\0&1\end{pmatrix},\]

que es la fórmula del paso siguiente. Tras cinco pasos hay 25 unidades; la segunda componente sigue siendo 3 unidades por paso. No es un segundo almacén ni un total acumulado. El modelo supone un incremento fijo: si la regla cambia, no podemos usar sin más la misma potencia.

5. Laboratorio de potencias

Cambia el exponente, consulta las potencias intermedias y abre el último producto. Prueba la matriz nula con n=0 y n=1, el intercambio con exponentes pares e impares y la acumulación con n=5.

Antes de mostrar una nueva potencia, intenta predecirla. Las variantes son nuevas bases de práctica, no preguntas adicionales del banco fijo. No hay puntuación ni historial.

6. Práctica y test

Sea \(B=\begin{pmatrix}1&2\\0&1\end{pmatrix}\). Calcula B², B³ y B⁵. Propón una expresión para Bⁿ y justifícala. Aplícala a \(w_0=\begin{pmatrix}4\\1\end{pmatrix}\) durante cinco pasos.

Pista

Compara la entrada (1,2) de B, B² y B³. Al multiplicar por B se añaden dos a esa entrada; las otras tres permanecen iguales.

Ver solución razonada

\[B^2=\begin{pmatrix}1&4\\0&1\end{pmatrix},\quad B^3=\begin{pmatrix}1&6\\0&1\end{pmatrix},\quad B^5=\begin{pmatrix}1&10\\0&1\end{pmatrix}.\]

Para n≥0, \(B^n=\begin{pmatrix}1&2n\\0&1\end{pmatrix}\). En n=0 da I; multiplicar por B cambia 2n por 2n+2=2(n+1), y conserva las demás entradas. Finalmente:

\[w_5=B^5w_0=\begin{pmatrix}1&10\\0&1\end{pmatrix}\begin{pmatrix}4\\1\end{pmatrix}=\begin{pmatrix}14\\1\end{pmatrix}.\]

7. Errores frecuentes

  • Elevar por separado las entradas de una matriz general.
  • Confundir A² con 2A o A⁰ con O.
  • Intentar calcular AA para una matriz no cuadrada.
  • Reordenar bases diferentes al usar leyes de exponentes.
  • Olvidar separar n=0 de los exponentes positivos en un patrón.
  • Afirmar una fórmula general sin justificar que pasa al siguiente exponente.
  • Usar Aⁿ cuando la transformación cambia en cada paso.

8. Resumen

Una potencia repite el producto de una base cuadrada. Empieza por A⁰=I y reutiliza Aⁿ para calcular Aⁿ⁺¹. Busca patrones, justifícalos y conserva el orden de los factores. Si el mismo proceso actúa n veces sobre un vector columna, su estado final es Aⁿv₀.
