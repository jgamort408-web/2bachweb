4.6. Determinante de una matriz

El determinante convierte una matriz cuadrada en un número. Aprender a calcularlo y distinguir cuándo vale cero prepara el estudio de inversas, rango y sistemas.

Objetivos · Definición · Cálculo · Interpretación · Ejemplos · Explorador · Práctica · Tarjetas

1. Qué vas a aprender

  • Distinguir una matriz de su determinante.
  • Calcular determinantes de orden 2 y 3, cuidando signos.
  • Decidir si una matriz cuadrada tiene inversa.
  • Encontrar valores de un parámetro que anulan el determinante.

Requisitos: orden de matrices, operaciones con números y producto matricial.

2. Un número asociado a una matriz cuadrada

El determinante de una matriz cuadrada A es un número calculado a partir de sus entradas mediante sumas de productos con signos. Se escribe \(\det(A)\) o \(|A|\). Aquí concretamos sus fórmulas en órdenes 1, 2 y 3.

La matriz y el número son objetos distintos:

\[A=\begin{pmatrix}1&2\\3&4\end{pmatrix},\qquad\det(A)=\begin{vmatrix}1&2\\3&4\end{vmatrix}=-2.\]

Las barras que rodean una matriz indican determinante; no obligan a que el resultado sea positivo. Para \(A=(a)\), de orden 1, se define \(\det(A)=a\). Una matriz no cuadrada no tiene determinante en este sentido: no se le asigna cero ni se completa con filas inventadas.

3. Fórmulas de cálculo

Orden 2

\[\begin{vmatrix}a&b\\c&d\end{vmatrix}=ad-bc.\]

Multiplica la diagonal principal y réstale el producto de la secundaria. Cada producto conserva los signos de sus factores.

Orden 3: regla de Sarrus

Para \(A=\begin{pmatrix}a&b&c\\d&e&f\\g&h&i\end{pmatrix}\),

\[\det(A)=aei+bfg+cdh-(ceg+afh+bdi).\]

Puedes repetir a la derecha las dos primeras columnas para identificar los seis recorridos:

\[\begin{array}{ccc|cc}a&b&c&a&b\\d&e&f&d&e\\g&h&i&g&h\end{array}\]

  • Los tres productos que descienden hacia la derecha son aei, bfg y cdh. Forman el grupo P.
  • Los tres recorridos que ascienden hacia la derecha dan ceg, afh y bdi. Forman el grupo Q.
  • Calcula P y Q por separado y termina con P−Q.

Los grupos indican qué se suma y qué se resta; sus valores pueden ser positivos, negativos o cero. Si Q es negativo, restarlo aumenta el resultado. La regla de Sarrus se aplica solo a orden 3. Repetir columnas de una matriz 4×4 no da una regla válida.

La copia de columnas es una ayuda para leer los productos, no modifica la matriz original. Cada producto toma un elemento de cada fila y de cada columna.

4. Qué nos dice el resultado

Una matriz cuadrada A tiene inversa cuando existe otra matriz A⁻¹ que cumple \(AA^{-1}=A^{-1}A=I\). Su cálculo se estudiará en 4.9. El criterio es:

\[A\text{ tiene inversa}\quad\Longleftrightarrow\quad\det(A)\ne0.\]

Un determinante negativo es tan válido como uno positivo para este criterio. Si det(A)=0, A no tiene inversa; se llama singular. Eso no significa que A sea la matriz nula.

Como avance de los apartados siguientes: el rango mide el máximo número de filas o columnas linealmente independientes. En una matriz cuadrada de orden n, det(A)≠0 implica rango n; det(A)=0 implica rango menor que n. Para el sistema Av=b, un determinante no nulo garantiza una única solución para cualquier b. Si es nulo, habrá ninguna o infinitas soluciones según b; hace falta estudiar más datos para decidirlo.

5. Ejemplos resueltos

Ejemplo 1. Restar un producto negativo

\[\begin{vmatrix}3&-2\\4&1\end{vmatrix}=3\cdot1-(-2)\cdot4=3-(-8)=11.\]

El segundo producto es −8. El signo menos exterior obliga a restarlo completo. Como 11≠0, la matriz tiene inversa.

Ejemplo 2. Un resultado negativo y una diagonal nula

\[\begin{vmatrix}1&2\\3&4\end{vmatrix}=4-6=-2.\]

La matriz tiene inversa porque −2 es distinto de cero. Tampoco una diagonal de ceros impide por sí sola la inversa:

\[\begin{vmatrix}0&1\\1&0\end{vmatrix}=0-1=-1.\]

No se mira solo la diagonal principal: el determinante utiliza ambas en orden 2.

Ejemplo 3. Sarrus paso a paso

\[A=\begin{pmatrix}1&2&3\\0&-1&4\\2&1&0\end{pmatrix}.\]

Grupo que se suma:

\[P=1(-1)0+2\cdot4\cdot2+3\cdot0\cdot1=0+16+0=16.\]

Grupo que se resta:

\[Q=3(-1)2+1\cdot4\cdot1+2\cdot0\cdot0=-6+4+0=-2.\]

\[\det(A)=P-Q=16-(-2)=18.\]

Hay seis productos de tres factores. Como el resultado es no nulo, A tiene inversa y rango 3.

Ejemplo 4. Una matriz con parámetro

\[A(k)=\begin{pmatrix}k&2\\3&k-1\end{pmatrix},\qquad\det(A(k))=k(k-1)-6=k^2-k-6=(k-3)(k+2).\]

El determinante se anula si k=3 o k=−2. En esos dos casos no hay inversa; para cualquier otro k real sí la hay. Comprobamos ambos valores:

\[k=3:\ 3\cdot2-2\cdot3=0,\qquad k=-2:\ (-2)(-3)-2\cdot3=0.\]

No basta encontrar una sola raíz. Tampoco se pide que el determinante sea positivo: solo distinto de cero.

Ejemplo 5. Determinante cero y sistemas

\[C=\begin{pmatrix}1&2\\2&4\end{pmatrix},\qquad\det(C)=4-4=0.\]

C no es nula, pero su segunda fila repite el doble de la primera y no tiene inversa. Consideremos dos sistemas con esta misma matriz:

\[\begin{cases}x+2y=3\\2x+4y=6\end{cases}\qquad\text{y}\qquad\begin{cases}x+2y=3\\2x+4y=7.\end{cases}\]

En el primero la segunda ecuación es el doble de la primera: hay infinitas soluciones \(y=t,\ x=3-2t\), con t real. En el segundo, duplicar la primera obliga a 2x+4y=6, en contradicción con 7: no hay solución. El mismo determinante cero aparece en ambos; no basta para decidir la compatibilidad.

7. Práctica y test

Calcula los determinantes de B y C y decide si tienen inversa:

\[B=\begin{pmatrix}2&1&0\\0&3&-1\\1&0&2\end{pmatrix},\qquad C=\begin{pmatrix}1&2\\3&6\end{pmatrix}.\]

Pista

En B, separa los dos grupos de Sarrus. Aunque hay varios ceros, conserva todos los productos para no omitir el que contiene −1. En C usa ad−bc.

Ver solución razonada

Para B:

\[P=2\cdot3\cdot2+1(-1)1+0\cdot0\cdot0=12-1+0=11,\]

\[Q=0\cdot3\cdot1+2(-1)0+1\cdot0\cdot2=0.\]

Por tanto det(B)=11 y B tiene inversa. Para C, det(C)=1·6−2·3=0; C no tiene inversa, aunque no es nula. Ningún resultado exige calcular todavía la propia inversa.

8. Errores frecuentes

  • Confundir la matriz con el número que representa su determinante.
  • Tomar valor absoluto porque aparecen barras.
  • Olvidar el signo exterior al restar productos negativos.
  • Usar solo tres productos en Sarrus o extenderlo a orden 4.
  • Asignar cero al determinante de una matriz no cuadrada.
  • Concluir que det(A)=0 implica A=O o que el sistema no tiene solución.
  • Exigir determinante positivo en vez de no nulo para tener inversa.

9. Resumen

Comprueba que la matriz sea cuadrada. En orden 2 calcula ad−bc; en orden 3 usa los seis productos de Sarrus y resta el segundo grupo completo. Un determinante distinto de cero garantiza inversa; uno nulo exige seguir estudiando rango y sistemas.
