9.5. Estimación puntual y estimación por intervalos

La media de una muestra puede estimar un parámetro desconocido; un intervalo expresa la incertidumbre del procedimiento.

Adaptación revisada de «2. Estimación.txt». Volver al tema 9.

Primero, identifica qué conoces

Población conocida → media de una muestra futura
Si conocemos la media poblacional \(\mu\), buscamos una región probable para la media muestral \(\bar X\). Es un intervalo de probabilidad para el estadístico aleatorio, que se calcula en 9.6. Intervalos característicos.
Muestra observada → parámetro poblacional desconocido
Si conocemos una media muestral \(\bar x\), usamos ese valor para estimar la media poblacional \(\mu\). \(\bar x\) es una estimación puntual; un intervalo de confianza añade un margen calculado bajo supuestos explícitos.

El original ilustra la primera pregunta con una media nacional de 170 y la segunda con una media observada de 172. Ninguna permite hallar límites numéricos sin conocer también, entre otros datos, el tamaño de la muestra y su variación relevante. No se puede invertir un intervalo para \(\bar X\) sin revisar qué cantidad se considera fija y cuál es aleatoria.

Nivel de confianza y significación

Para un intervalo bilateral con nivel de confianza \(1-\alpha\), la significación \(\alpha\) se reparte entre las dos colas de una normal estándar \(Z\). El valor crítico positivo \(z_{\alpha/2}\) se define por:

\[P(Z>z_{\alpha/2})=\frac{\alpha}{2},\qquad P(-z_{\alpha/2}\le Z\le z_{\alpha/2})=1-\alpha.\]

Un nivel del 95 % significa que, si repitiéramos el muestreo y la construcción del intervalo bajo el mismo modelo, aproximadamente el 95 % de los intervalos cubriría el parámetro fijo. Una vez calculado un intervalo concreto, el parámetro no pasa a ser aleatorio y no se interpreta que «tenga un 95 % de probabilidad de estar dentro».

En la fórmula normal bilateral con parámetro sin cota, exigir un 100 % de cobertura lleva el valor crítico y la anchura al infinito. Esa observación se refiere a este procedimiento, no a toda forma posible de intervalo.

Intervalo de confianza para la media

Si \(X_1,\ldots,X_n\) son observaciones independientes de una población normal con desviación típica poblacional \(\sigma\) conocida, el intervalo bilateral habitual para \(\mu\) es:

\[IC_{1-\alpha}(\mu)=\left[\bar x-z_{\alpha/2}\frac{\sigma}{\sqrt n},\;\bar x+z_{\alpha/2}\frac{\sigma}{\sqrt n}\right].\]

El centro es la estimación puntual \(\bar x\). El margen de error de este procedimiento es \(E=z_{\alpha/2}\sigma/\sqrt n\), la mitad de la anchura del intervalo. «Error máximo admisible» designa un objetivo fijado antes del estudio; no debe confundirse con el margen calculado después.

Si la población no es normal, la fórmula con \(z\) puede ser aproximada para muestras apropiadas por el teorema central del límite. No hay un tamaño universal que garantice precisión. Si \(\sigma\) es desconocida, sustituirla sin más por \(s\) cambia el procedimiento; bajo normalidad suele emplearse la distribución \(t\) de Student. También pueden hacer falta correcciones por muestreo sin reemplazo o por un diseño complejo.

Para construir el intervalo hacen falta \(\bar x\), \(n\), una medida de dispersión y un nivel de confianza, además de comprobar el diseño y los supuestos. La fuente solo da ejemplos de dirección con 170 y 172, así que no se inventan límites numéricos.
