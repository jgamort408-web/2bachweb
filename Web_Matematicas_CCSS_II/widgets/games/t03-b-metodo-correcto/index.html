Método correcto

Primero decide cómo empezar; después encuentra la familia de primitivas. Ocho retos variables con cuatro estrategias.

Cómo jugar y cómo se puntúa

En cada reto elige la ruta más directa entre las propuestas: tabla, cadena al revés, simplificación previa o integración por partes. Las categorías orientan la decisión; una integral puede admitir varios caminos válidos. Aquí se valora reconocer el patrón destacado: tabla básica para potencias de x y eˣ; cadena si hay una función interior no trivial; simplificar si una división o cancelación reduce el cálculo. No se afirma que estas sean las únicas rutas válidas. Los dos retos por partes son una ampliación de la lección 3.4.

Tras decidir el método se desbloquea la elección de la familia completa de primitivas. Cada uno de los 16 pasos permite dos intentos: 100 puntos al primero, 50 al segundo y 0 si se muestra la solución tras dos errores. Máximo: 1600 puntos. Las pistas no penalizan y se cuentan una vez por paso. No hay reloj.

Usa Tab para recorrer controles, flechas y Espacio para seleccionar, y Enter en los botones. Las variantes pueden repetirse. Solo se guardan las preferencias de lectura; las respuestas y puntuaciones se pierden al recargar.
