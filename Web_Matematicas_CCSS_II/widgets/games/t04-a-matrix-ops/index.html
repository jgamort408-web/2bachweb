Matrix Ops

Supera ocho retos de matrices. Comprueba primero qué puedes hacer y después calcula: tipos, suma, resta, escala, productos y potencias.

Cómo jugar y cómo se puntúa

Cada reto tiene dos pasos. Primero clasifica la matriz o decide si la operación está definida y qué tamaño tendrá. Después elige el resultado; si el producto no existe, justifica por qué. Resolver el primer paso desbloquea el segundo.

Hay 16 decisiones: 100 puntos al primer intento, 50 al segundo y 0 si se muestra la solución tras dos errores. Máximo: 1600 puntos. Las pistas no penalizan y se cuentan una vez por paso. No hay reloj ni arrastre obligatorio.

Usa Tab para recorrer los controles, flechas y Espacio para seleccionar, y Enter en los botones. Las matrices anchas se pueden desplazar horizontalmente dentro de la fórmula. Una nueva sesión cambia números y orden; algunas variantes pueden repetirse. Solo se guardan las preferencias de lectura: respuestas y puntuación se reinician al recargar.
