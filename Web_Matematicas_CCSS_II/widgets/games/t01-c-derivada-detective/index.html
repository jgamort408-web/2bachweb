Derivada Detective

Ocho casos con datos nuevos: cinco para elegir la derivada y justificar el procedimiento; tres para localizar el primer paso erróneo.

Cómo investigar

Son trece decisiones sin límite de tiempo. Después de cada derivada tendrás que elegir la regla principal; las composiciones interiores también pueden necesitar otras reglas. En los desarrollos, busca el primer error aunque los pasos siguientes lo arrastren.

Dispones de una pista y un segundo intento. El resumen cuenta los aciertos al primer intento, incluso si consultaste la pista. No se guarda un historial. Al reiniciar se generan otros datos.
