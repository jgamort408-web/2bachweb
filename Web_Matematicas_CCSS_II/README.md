## Abrir el proyecto

Desde esta carpeta, con Node.js disponible:

```text
node scripts/serve.mjs
```

Abre `http://127.0.0.1:4173/`. Detén el servidor con Ctrl+C.

También puedes publicar esta carpeta como sitio estático. Los fragmentos compartidos se cargan mediante peticiones HTTP, por lo que abrir un HTML con doble clic (`file://`) no garantiza que aparezcan la cabecera y el pie. No se requieren paquetes npm ni una compilación.

## Cómo ampliar una página

1. Localiza su HTML mediante `config/pages.json`.
2. Añade el contenido futuro dentro de `<main id="main-content">`, después del título.
3. Mantén `data-page-id`, el módulo de inicialización y los contenedores de cabecera/pie.
4. Para crear otra página, copia cualquier HTML, ajusta título e ID y ejecuta `npm run fix:links`: recalcula los prefijos `../` de CSS, JS y enlaces según la nueva profundidad. Después registra su entrada en el catálogo. `npm run check:links` (también incluido en `npm test`) informa de cualquier enlace local roto o ruta absoluta que fallaría en la subcarpeta de GitHub Pages.
5. Usa `parentId` para conectarla con su sección. Las páginas relacionadas y los enlaces entre epígrafes se calculan desde ese catálogo.

No dupliques la cabecera o el pie dentro de cada página. Para añadir enlaces fijos a un fragmento compartido, usa `data-project-path="ruta/archivo.html"`; el cargador resolverá su dirección desde la raíz del proyecto.

## Videojuegos como widgets independientes

Las 28 actividades tienen su carpeta con HTML, CSS y JavaScript. Están desarrollados diecinueve widgets: cuatro del tema 1 y tres de cada uno de los temas 2, 3, 4, 5 y 7. Los nueve de los temas 6, 8 y 9 conservan su esqueleto y se rigen por el criterio de reutilización de originales.

El catálogo relaciona cada widget con su tema y página anfitriona. Los diecinueve juegos desarrollados se insertan mediante assets/js/learning/embed.js y también pueden abrirse por separado.

Los widgets no llevan la cabecera y el pie generales, pues al insertarlos esos elementos pertenecen a la página anfitriona. El iframe aísla sus estilos. La base opcional está en `widgets/shared/`; cada juego puede añadir su propio código sin modificar los demás.

Para insertar un juego en una fase posterior:

```js
import { mountWidget } from './assets/js/shared/widget-host.js';
// widget es una entrada de config/widgets.json; adapta la ruta del import a la página.
const instance = mountWidget(container, widget);
// Al retirar el juego: instance.destroy();
```

El anfitrión recibe cambios de altura mediante mensajes del widget, comprobando origen, ventana e identificador. El protocolo inicial solo incluye `ready` y `resize`: no guarda puntuaciones ni activa seguimiento. Esta primera integración está pensada para widgets locales del mismo origen; insertar desde otro dominio requerirá configurar y validar los orígenes admitidos.

El motor de práctica puede reutilizarse; cada actividad conserva su generador y lógica específica. Límite Express organiza sus familias algebraicas, preguntas gráficas y elección de método en cuatro niveles; admite rondas especiales y reloj opcional.
